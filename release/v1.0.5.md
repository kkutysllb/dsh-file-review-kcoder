# dsh-file-review-kcoder 1.0.5

> dsh 0.1.6-alpha.2 适配版：typert codec create() 工厂 + turnTail 槽位
> chain → list 语义重写。

## 背景

alpha.2 的两处硬断曾导致本插件在 09-18 被整体退役：

1. **typert-loader 严格注册校验**：strict codec 须以 `create()` 工厂懒物化
   schema；旧形态的饿汉 `schema` 字段过不了校验，且失败发生在 loader 的
   激活事务里——cordis 回滚 fiber 时把已注册的**全部**远端定义一并撤回
   （session/control、pluginInventory 等全数失联的根因）。
2. **turnTail 槽位 chain → list**：注册必须带 `id`，`select`/`priority`
   不再被消费（旧注册直接抛 `list slot requires options.id`）。

## 变更

- **codec 双字段兼容**（×5）：`create()`（alpha.2 运行时消费）+
  `schema`（pre-alpha.2 运行时消费）并存；对象经 const 持有（非新鲜
  字面量），旧类型基线不做多余属性检查，两侧编译与运行均兼容。
- **turnTail 双轨注册**：`id`（alpha.2 list）+ `select`/`priority`（旧
  引擎 chain，旧类型基线下 select 必填）齐供；匹配判定移入
  `FileReviewTurnTail` 组件（每次渲染重算，list 语义的正确形态；旧
  chain 引擎下框架传入的 matched 被重算覆盖，值恒等）。
- peer 范围：11 个 `@deepseek-ai/dsh-*` 追加 `|| 0.1.6-alpha.2`。

## 共存协调（与 coding-sidebar 1.0.19 对齐）

chain 时代 priority -2 抢占不复存在，三层互让：changes 公告 → 原生卡；
本插件 fileReviewChanges → 本卡（增强：hunks/统计/撤销 + 产物与交付
两段）；其余 → coding-sidebar 产物行兜底。同一 turn 永不双行。

## 验证

typecheck / build / smoke（13/13，含交付认领与空匹配渲染）全过；
与 coding-sidebar 1.0.19 双插件 alpha.2 引擎活体共载：host 半激活无告警、
typert 注册无撤回、turnTail 无槽位错误、零页面错误。

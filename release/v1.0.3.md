# dsh-file-review-kcoder 1.0.3

## 修复

- **dsh 0.1.5 交付物卡片被吞（兼容修复）**：dsh 0.1.5-alpha.2 起 `present` 工具把显式交付写进同一份 `deliverables` turn data（新增 `presented` 字段），内置 ui-deliverables 轮尾行据此渲染交付卡片。轮尾槽 `conversation.chat.turnTail` 是 **CHAIN**：首个返回非 null 的选择器独占该行。此前本插件的选择器（priority −2）只按 `produced`（改动文件）认领，于是**既改文件又 present** 的轮次会把新交付卡片整段吞掉——正是推荐的用法（「写完就 present」）。现在认领同时读取两个面，并由插件的 `Deliverables` 行组件把两段都渲染出来：改动卡片（原有：diff 统计 / 撤销 / 侧栏深链）+ 交付卡片（新增）。
- **交付卡片**（新组件 `PresentedFiles`）：镜像内置卡片的度量与交互契约——单个交付整行、多个两列 10px 网格、超过 4 个折叠并给展开入口；卡片主体点击走本插件自己的侧栏查看器管线预览，「打开」拆分为默认应用打开 + 文件管理器显示（访达 / 资源管理器 / 所在文件夹，按主机 `fileManager` 文案）；失败态可点重试。主机无桌面时隐藏原生入口并提示，仅保留侧栏预览。
- **系统提示段重复**：内置 ui-deliverables 自 dsh 0.1.0-rc.7 起就注册了与插件逐字相同的文本段（`ui:deliverable-file-references`）。两个不同名的段会同时进入提示词，等于把同一段指引说了两遍。现在仅在老载体上注册自有副本：dsh 0.1.2-alpha.1 起 `DELIVERABLE_FILE_REFERENCES` 位置常量可探测，探测到即说明内置插件已拥有该指引，插件让位；常量不存在（更老的载体）时保持原行为。

## 变更

- 新模块 `client/present-open.ts`（原生打开控制器：`/api/present.host` 元数据 + `/api/present.open` 动作，404 视为「载体无交付路由」并永久降级为仅侧栏预览，422 视为「无可用主机路径」）；新组件 `client/PresentedFiles.tsx` + `client/Deliverables.tsx`（被选举的行组件，组合改动卡片与交付卡片）。
- `client/turn-deliverables.ts`：`selectDeliverables` 取代 `selectDeliverablePaths`，认领值由 `readonly string[]` 变为 `{ produced, presented }`；新增 `presentedForClosing` / `isPresentedPath` / `extensionOf` / `cleanDescription`。
- 新增文案键 30 个（`presented.*`，zh / en 双语，键集与内置 `deliverables` 命名空间对齐）。
- `lib/client.js` 追加纯函数导出 `selectDeliverables` / `presentedForClosing` 与行组件 `Deliverables`（供渲染级回归校验，向后兼容）。
- 新增 `pnpm smoke:render`（`scripts/smoke-render.mjs`）：加载真实发布物、渲染轮尾行、断言「认领后两段都渲染」，并入 `pnpm smoke` / `prepack`。

## 兼容性

- **无破坏性变更**；dsh 基线不变（`0.1.2-alpha.1+`，建议 `0.1.2-alpha.4+`）。
- 老载体（dsh < 0.1.5-alpha.2，turn data 无 `presented`）行为完全不变：交付段不渲染，仅改动卡片；原生打开控制器不发起任何请求。
- 交付卡片通过**同源 HTTP 路由**调用主机能力，不引入对 `@deepseek-ai/*` 运行时的导入（客户端半仍只做类型导入），因此跨 dsh 小版本的导出变动不影响本插件。
- 若组态移除了内置 ui-deliverables（其自带指引、行、行内链接一同消失），插件的原生打开路由同步消失并自动降级为仅侧栏预览。

## 回归校验

`pnpm smoke` = 形态/行为检查 40 项（原有 33 项 + 认领不变量 7 项）+ 渲染检查 13 项，发布前自动执行。

## 安装

```bash
dsh plugin --profile web add dsh-file-review-kcoder
```

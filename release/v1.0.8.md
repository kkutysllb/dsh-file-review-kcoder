# dsh-file-review-kcoder 1.0.8

> dsh 0.1.7-alpha.1 契约迁移适配版（typecheck 19 错 / 6 根因，零删功能）。

## 背景

引擎 0.1.7-alpha.1 的契约面变动与本仓编译面冲突，共 19 处错误，归为 6 个根因；
另有两处安装期阻断。适配一律以「结构面镜像 + 逐条注明 fork 权威路径」的方式
落在本仓，不改上游、不用 `as any` / `@ts-ignore`、不删功能。

## 变更

- **依赖面**：devDeps 平移 0.1.7-alpha.1；删除已死的
  `@deepseek-ai/dsh-client-runtime`，补 `dsh-api-session-controller` /
  `dsh-session`；peer 追加 `^0.1.7-alpha.1`。
- **安装阻断修复**：`autoInstallPeers=false`（0.1.7 的 peer 链存在「只有
  预发布范围可满足」的组合，pnpm 会退化成熟稳定范围后报无匹配）；
  `allowBuilds` 放行 node-pty / protobufjs。
- **契约适配**（新增 `src/client/dsh-contracts.ts` 结构面镜像）：
  ConversationSnapshot 新形状（转录切片移至 chat target 的 legacy）、
  SessionStandardProps.sessionId（ui-session merge）、`connection/reset`
  事件、`ctx.slots` → SlotRegistryFace 服务代理、TurnTailOwnerProps 移至
  ui-chat、`ctx.remote.$mount` 签名恢复。
- **路由文档相对化**：present.host / present.open 去掉前导斜杠（0.1.7 约定；
  前缀剥离反代下修复 404，根部署等价）。

## 验证

typecheck 0 错；build 成功；smoke 45 + render 13 全绿（无 `as any` /
`@ts-ignore`、无删功能）。

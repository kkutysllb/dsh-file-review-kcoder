# dsh-file-review-kcoder 1.0.9

> 0.1.7 共享文件动作子槽（`deliverables.file.actions`）+ present 打开链路
> `application` 参数（open-with）。

## 变更

- **turn-tail 注册声明子槽**：声明 `children: deliverables.file.actions`
  （list/session，逐字对齐 fork `ui-deliverables/src/client/index.ts:83`），
  带 `rendersExistingChildren`（KCoder fork 分歧）；注册被拒时退回无 children
  形态，并以 inject 面 `fileActionsSlot` 挡住非法 renderSlot 调用（不炸插件）。
- **逐文件渲染 + fallback**：每张交付卡逐文件渲染该子槽，自带分体控件作为
  fallback（无贡献者时零回归）；owner props 逐字对齐 fork
  `file-actions.ts:8-19` `{actionUrl, available, pending, onAction}`。
- **present 打开链路补 `application` 参数**：URL 组合逐字镜像 fork（reveal
  不带 application、无参调用字节不变）；`open()` 返回 `PresentedOpenFailure`。
- **有意不实现** `deliverables.review.file.actions`：本仓评审面非 slot 组件、
  缺 changes 摘要坐标，声明反而会独占声明权、掐掉原生 tab 的动作位。

## 验证

- 测试：smoke 45 → **65**、render 13 → **24**（含「声明确实让子槽出现」
  「卡片渲染出宿主贡献的动作」「重复声明两分支」「共享渲染面释放语义」）；
- 引擎级验证：用 KCoder 运行时真实 SlotCore 跑真实产物注册项
  （`tailCard=false` 形态 / 贡献者注册 / ownedChildren 释放语义）；
- 门禁：typecheck 0 错、build、smoke 65 + render 24 全绿。

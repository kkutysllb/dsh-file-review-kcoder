# dsh-file-review-kcoder 1.0.2

## 新增

- **非代码产物预览**：审查面板此前只覆盖可 diff 的文本变更；现在图片 / 音视频 / Office / PDF / 文档类产出以类型徽标（图片 / 视频 / 音频 / Office / PDF / 文档）呈现，点击走 dsh-coding-sidebar 的文件查看器管线预览（`betterSidebar.openFile` → editor tab → `matchFileViewer`：image / pdf / markdown / html 内置，office / video 查看器插件懒加载；无侧栏时降级为宿主 OS 默认应用打开）。轮尾卡片与侧栏 Tab 两侧一致；artifact 行不参与 undo/巡检，避免假失败提示。
- **bash 产物捕获**：图片等二进制产物通常经终端产生、不在 write/edit 词汇内。`fileReviewChanges` Definition 与窗口派生新增保守捕获：仅限已知产物扩展名 + 明确输出语法（重定向 `>`/`>>`、`curl -o`/`--output`、`wget -O`、`cp`/`mv` 末位参数、`tee`），支持引号目标；普通代码命令零误报。

## 变更

- 新模块 `client/artifacts.ts`（`ArtifactKind` / `classifyPath` / `captureArtifacts`）；`lib/client.js` 追加 `classifyPath` / `captureArtifacts` 纯函数导出（供产物级回归校验，向后兼容）。
- 新增文案键：`produced.kind*` 六类徽标与 `produced.preview`（chat 命名空间）、`kind*`（tab 命名空间），zh / en 双语。
- 轮尾卡片「另有 N 个文件」展开能力延续至新列表形态（1.0.1 引入的展开/收起按钮对产物 chip 同样生效）。

## 兼容性

- 无破坏性变更；dsh 基线不变（`0.1.2-alpha.1+`，建议 `0.1.2-alpha.4+`）。
- 预览深度依赖 dsh-coding-sidebar 的查看器能力：无侧栏 / 侧栏查看器被禁用时按路径回退（宿主 OS 默认应用或仅列表展示）。

## 回归校验

`pnpm smoke` 产物级行为检查共 19 条（流式抖动免疫 / turn 隔离 / 内容敏感 / 回退路径 / 巡检键；产物分类 / bash 捕获 / 引号目标 / 零误报 / 非 shell 不捕获），合计 33 项，发布前自动执行。

## 安装

```bash
dsh plugin --profile web add dsh-file-review-kcoder
```
